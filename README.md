# Namishka Singh — Portfolio

My personal portfolio site, built to showcase my projects, experience, and skills as a Computer Science student.

**Live site:** [namishkasingh.github.io/portfolio](https://namishkasingh.github.io/portfolio) <!-- update this link once GitHub Pages is live -->

## About

I'm a Computer Science undergraduate at Banasthali Vidyapith, building full-stack and AI-driven applications. This site covers my background, projects, and the tools I work with.

## Built with

- HTML, CSS, and vanilla JavaScript (no framework, single file)
- [Three.js](https://threejs.org/) for the 3D node-network visuals in the hero and section dividers
- Google Fonts (Space Grotesk, Inter, JetBrains Mono)

## Features

- Interactive 3D particle network in the hero, built with Three.js
- Project cards with a 3D tilt-on-hover effect
- "View More" popups with a full write-up and tech stack for each project
- Fully responsive layout
- No build step or dependencies — it's a single `index.html` file

## Running it locally

No installation needed. Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/namishkasingh/portfolio.git
cd portfolio
open index.html   # or just double-click the file
```

An internet connection is needed for the 3D visuals and fonts to load, since they're pulled from a CDN.

## Deployment

This site is deployed with [GitHub Pages](https://pages.github.com/), served directly from the `main` branch.
